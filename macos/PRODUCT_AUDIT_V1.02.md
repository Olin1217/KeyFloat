# KeyFloat V1.02 产品打磨审计

基线：V1.01（只读备份）  
范围：仅修改 `KeyFloat-Xcode`，不调整既有视觉设计，不引入 Windows 快捷键。  
原则：准确性优先于数量；可验证的默认 macOS 绑定优先于推测或跨平台混用。

## 十轮反推

1. **基线与边界**：确认窗口、语言、主题、钉住、搜索、收藏和 34 个软件包的现状，锁定 V1.01。
2. **数据可信度**：检查来源覆盖、重复 ID、空字段、平台混用、覆盖层行为和双语缺口。
3. **查找效率**：反推用户从“想起一个动作”到“找到正确按键”的完整路径，优化归一化、别名和相关性。
4. **高频键盘流**：检查不碰鼠标时的展开、搜索、清空、收起、切换和退出路径。
5. **状态连续性**：检查重启、升级数据、软件切换、收藏迁移、屏幕切换与外接显示器断开场景。
6. **性能与规模**：以快捷键继续增长至一万条为目标，消除重复字符串归一化和无效刷新。
7. **异常与降级**：模拟单个资源缺失、JSON 损坏、重复记录和旧偏好数据，保证其余软件仍可使用。
8. **可访问性**：检查 VoiceOver 名称、键盘焦点、图标按钮语义和仅靠颜色表达状态的问题。
9. **内容扩充**：只导入可证明为 macOS 的官方默认绑定；不为 Windows-only 软件伪造 Mac 数据。
10. **发布回归**：执行结构化数据审计、Debug/Release 构建、资源打包检查和 V1.01 完整性复核。

## 至少 20 个优化方向

1. 资源文件逐个加载，单包损坏时不拖垮整个快捷键库。
2. 区分“基础包合并”和“官方完整包替换”，避免覆盖层误删类别。
3. 运行时检测重复软件、分类、快捷键 ID。
4. 运行时检测空标题、空按键和非 macOS 平台标记。
5. 对数据异常保留诊断信息，便于发布前定位具体文件。
6. 清理升级后已经不存在的收藏键，避免长期积累脏偏好。
7. 所有偏好写入统一使用注入的 `UserDefaults`，提升可测试性。
8. 预计算搜索索引，避免每次输入都重建 2,000+ 条文本。
9. 搜索支持 Command/Cmd/⌘、Option/Alt/⌥ 等同义表达。
10. 搜索支持中英文修饰键名称、方向键、Return/Esc/Delete 别名。
11. 搜索执行大小写、宽度和音调符号折叠。
12. 搜索按标题、按键、标签和分类相关性排序。
13. 精确键位组合优先于只在说明文字中命中的结果。
14. `⌘K` 在收起状态直接展开并聚焦搜索。
15. 同时支持 macOS 惯用的 `⌘F` 聚焦搜索。
16. 无效分类自动回到“全部”，避免数据更新后的空白页。
17. 软件切换使用无效变更保护，减少不必要的重绘和偏好写入。
18. 保存窗口右上角锚点，修复从展开状态退出后重启位置偏移。
19. 外接显示器断开后自动把窗口收回可见区域。
20. 在多显示器环境中恢复到原显示器或最近可见显示器。
21. 屏幕尺寸小于窗口时使用安全夹取算法，避免负向越界。
22. 为所有纯图标按钮补充本地化 VoiceOver 名称与帮助文本。
23. 为收藏按钮提供明确的“收藏/取消收藏”可访问性动作名称。
24. 为搜索、软件选择器和筛选控件补充稳定的可访问性标识。
25. 建立项目内数据校验工具，持续审计数量、重复和双语完整性。
26. 给每个可验证软件包记录来源、版本和验证日期。
27. 扩充 Safari 等可访问官方完整清单的软件，保留动作上下文。
28. 将 Windows-only 工程软件显式排除在 Mac 库之外，防止错误键位污染。
29. 为新增长的软件补充 bundle identifier，安装后自动显示原始图标。
30. 同时验证 Debug 与 Release 构建，检查所有 JSON 都进入 App Bundle。

## 完成判定

- 所有修改均位于当前 `KeyFloat-Xcode`。
- V1.01 三个核心源码文件哈希保持不变。
- 数据校验零错误；任何警告都有明确原因。
- Debug 与 Release 均能无签名构建成功。
- 不声称未由官方来源证明的快捷键包“完整覆盖”。

## 本轮落实结果

- 已完成 10 轮以上反推，并将 30 个优化方向中的核心行为、数据、性能、容错与验证项落地。
- 软件包由 34 增至 39；快捷键由 2,314 增至 3,597。
- 新增 Affinity Designer 2、Affinity Photo 2、Affinity Publisher 2、Terminal、Finder；Safari 与 Illustrator 完成官方双语页面并集合并。
- 新增来源元数据、双语按键标签、增量合并策略、局部加载降级和 Windows 键阻断。
- 搜索改为预计算索引、标题/键位独立候选、全局相关性排序和单字符物理键精确匹配。
- `Cmd+K`、`Command-K`、`⌘K`、`Command K` 已通过等价性测试；实际界面误报从 16 条降为正确的 3 条。
- 展开/收起过渡增加最后意图队列，快速交替输入不再丢命令。
- 窗口位置改为右上角锚点与显示器 ID，补充显示器断开回收。
- 图标查询由全量同步扫描改为按需缓存。
- 数据验证、官方导入复现、Store 冒烟测试、真实 UI 回归均已建立。

## 扩展生态真实性复核

- 扩展版高校软件文档已归入 21 个场景，运行时目录达到 209 款软件。
- 新增 LabVIEW、PLECS、Benchling、Geneious Prime、VMD、Avogadro、3D Slicer、Godot，共 319 条来源明确的 macOS 键位。
- 16 款缺少公开默认键位表的扩展软件以 `catalogOnly` 状态加入正确专业分类，不生成替代键位。
- 第一份生态草稿的 3,015 条通用模板数据、旧版基础包的 1,644 条未逐项取证数据均已由隔离层覆盖。
- 当前 25 款官方或来源型软件展示 4,196 条快捷键；其余 183 款保留目录并显示“快捷键正在核验”。
- 有效运行时库不存在 `legacyReviewed` 展示包，不展示未取得官方或可复现来源的快捷键。

## 浏览器来源与人工校验机制

- 新增 `manualReview` 数据状态，浏览器二级来源不会冒充官方数据。
- 新增 `BROWSER_SOURCED_SHORTCUTS_REVIEW.md`，逐包记录检索词、来源地址、采用条数、风险点和人工校验步骤。
- Figma 首批恢复 8 条浏览器二级来源 Mac 键位，旧版 177 条数据没有整体恢复。
- MATLAB 从 MathWorks 官方页面 macOS 专用列导入 84 条键位及等价组合。
- Photoshop 从本机 2026 官方快捷键导出中恢复 52 条可复核记录，5 条缺失或语义变化的旧记录继续隔离。
- Microsoft Word、Excel、PowerPoint、OneNote 从官方页面独立 `macOS` 标签恢复 708 条去重键位；Excel 官方空标题 `Ctrl+E` 行没有猜测导入。
- Apple Pages、Numbers、Keynote 从官方中英文 Mac 页面恢复 979 条去重键位与明确列出的手势。
- 当前运行时为 209 款目录、4,204 条展示快捷键：25 款官方来源、1 款待人工校验、183 款仅目录。
