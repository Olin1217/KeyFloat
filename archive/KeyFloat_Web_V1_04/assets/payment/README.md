# Alipay QR asset

`alipay-qr.png` is the production ¥6 KeyFloat collection QR used by the website checkout.

Source: KeyFloat Figma file, QR image layer `86:285`. The image is stored locally because temporary Figma asset URLs expire.

Do not resize, recompress, redraw, or replace this image with a placeholder. The checkout page displays price and product context separately so the QR stays large and scannable.
