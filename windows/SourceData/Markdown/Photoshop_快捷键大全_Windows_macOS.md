# Adobe Photoshop 快捷键大全（Windows / macOS）

> 适用范围：Adobe Photoshop 桌面版；整理日期：2026-07-25  
> 内容基准：Adobe 官方 Photoshop 快捷键文档、Photoshop 2026 年版帮助中心、Adobe Camera Raw 官方快捷键文档。  
> 不包含：Photoshop 网页版、iPad 版、第三方插件及个人自定义快捷键。

## 使用说明

- `Ctrl` 对应 macOS 的 `Command`；`Alt` 对应 macOS 的 `Option`。
- `单击/拖动` 表示配合鼠标或触控板操作。
- 同一工具组共享一个字母键；默认按 `Shift + 工具键` 在组内切换。若关闭“使用 Shift 键切换工具”，连续按工具键即可切换。
- macOS 顶部功能键常被亮度、音量占用，使用 `F1–F12` 时可能还要按住 `Fn`。
- 部分快捷键只在对应工具、面板、对话框或工作区激活时生效。
- 不同 Photoshop 版本、键盘布局与自定义设置可能产生差异。要导出你当前版本的绝对完整列表：进入 `编辑 > 键盘快捷键`，再选择“摘要 / Summarize”。

## 20. 自定义、导出与版本核对

### 20.1 查看当前安装版本的完整快捷键

1. 打开 Photoshop。
2. 选择 `编辑 > 键盘快捷键`。
3. 或直接按：
   - Windows：`Alt + Shift + Ctrl + K`
   - macOS：`Option + Shift + Command + K`
4. 在“快捷键用于”中分别查看：
   - 应用程序菜单（Application Menus）
   - 面板菜单（Panel Menus）
   - 工具（Tools）
   - 任务空间（Taskspaces）
5. 点击“摘要 / Summarize”，导出当前版本、当前快捷键集的 HTML 列表。

这份导出的 HTML 是核对特定 Photoshop 版本、语言、工作区和自定义键位时最权威的结果。

### 20.2 自定义快捷键

- 在 `编辑 > 键盘快捷键` 中选择命令或工具，再输入新组合键。
- 若新组合键与现有命令冲突，Photoshop 会显示警告；可选择接受并转到冲突项。
- 建议另存为新的快捷键集，不直接覆盖 Photoshop 默认集。
- Photoshop 的自定义快捷键集通常以 `.kys` 文件保存。

### 20.3 容易混淆的情况

- `数字键`：绘画工具激活时通常控制画笔不透明度；移动工具等激活时通常控制图层不透明度。
- `Shift + 数字键`：绘画工具下通常控制流量；非绘画工具下通常控制图层填充。
- `Ctrl/Command + 1–9`：在 Photoshop 主界面、Camera Raw 和不同对话框中的含义不同。
- `Ctrl/Command + H`：可能隐藏额外内容、选区边缘或特定工作区内容，取决于当前上下文。
- `F1–F12`：macOS 常需配合 `Fn`；系统设置也可能改变功能键行为。
- 自由变换中的 `Shift`：新版 Photoshop 默认保持比例，按住 `Shift` 会临时反转当前缩放行为；旧版或启用“旧版自由变换”时行为可能相反。
- 非英文键盘布局中的 `` ` ``、`~`、`[`、`]`、`;`、`'` 等位置可能不同。
