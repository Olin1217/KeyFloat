# Adobe Illustrator 快捷键大全（Windows / macOS）

> 适用范围：Adobe Illustrator 桌面版（Windows / macOS）  
> 整理日期：2026-07-25  
> 内容基准：Adobe 2026 年版官方快捷键页、桌面版工具清单、快捷键自定义与导出文档。  
> 不包含：Illustrator iPad 版、第三方插件快捷键、用户自行修改的快捷键。

## 使用说明

- `Ctrl` 在 macOS 上通常对应 `Command`；`Alt` 对应 `Option`。
- `单击`、`双击`、`拖动`表示按住相应修饰键后配合鼠标或触控板操作。
- 部分快捷键只在指定工具、面板、输入框或编辑状态下生效，已在“说明”中标注。
- 单字母工具键通常需要在非文字输入状态下使用。
- macOS 顶部功能键可能被亮度、音量等系统功能占用，使用 `F1–F12` 时可能还要按 `Fn`。
- 不同语言键盘布局会影响 `` ` ``、`~`、`\`、`/`、`[`、`]`、`;`、`'` 等符号键的位置。
- Adobe 允许修改工具键和菜单命令。若本机结果不同，请进入 `编辑 > 键盘快捷键`，选择 `Illustrator Defaults` 核对。
- Adobe 旧帮助页曾把 `Ctrl / Command + E` 写作“轮廓/预览”；当前 2026 默认表中：
  - `Ctrl / Command + Y`：轮廓视图与 GPU 预览切换；
  - `Ctrl / Command + E`：GPU 预览与 CPU 预览切换。
- 本文优先保留当前 2026 官方定义；个别 Adobe 网页排版截断项已按 Windows/macOS 对称规则整理，并在必要处注明。

## 22. 自定义、导出与备份

### 22.1 在 Illustrator 中核对或修改

1. 进入 `编辑 > 键盘快捷键`。
2. 在快捷键类型中选择：
   - `工具`：修改工具键；
   - `菜单命令`：修改文件、编辑、对象、文字、选择、效果、视图、窗口等命令。
3. 如果只想查看系统默认值，在“设置”中选择 `Illustrator Defaults`。
4. 输入自定义组合键时，注意系统级、输入法级和 Illustrator 内部冲突提示。
5. 保存为新的快捷键集，不建议直接覆盖默认集。

### 22.2 导出本机绝对完整列表

Adobe 官方提供导出功能，可导出当前 Illustrator 版本中“默认 + 已自定义”的工具和菜单命令：

1. 进入 `编辑 > 键盘快捷键`。
2. 从“设置”下拉框选择要导出的快捷键集。
3. 选择 `导出文本（Export Text）`。
4. 命名并保存 `.txt` 文件。

这一步是核对特定 Illustrator 小版本、语言包、键盘布局和个人设置时最可靠的方法。

### 22.3 备份或迁移 `.kys` 快捷键文件

Illustrator 自定义快捷键集使用 `.kys` 文件。

| 平台 | 官方位置格式 |
|---|---|
| Windows | `C:\Users\<用户名>\AppData\Roaming\Adobe\Adobe Illustrator <版本> Settings\<语言>\x64\<快捷键文件名>.kys` |
| macOS | `~/Library/Preferences/Adobe Illustrator <版本> Settings/<语言>/<快捷键文件名>.kys` |

复制 `.kys` 文件可以备份、迁移或共享快捷键集。替换前建议保留原文件，并在 Illustrator 关闭时操作。
