## 1. 按键符号与使用说明

| 写法 | 含义 |
|---|---|
| `Ctrl + M` | 同时按住 `Ctrl` 和 `M` |
| `Alt, H, L` | 依次按下，不必同时按 |
| `Cmd` | macOS / iPadOS 的 Command（⌘）键 |
| `Option` | macOS / iPadOS 的 Option（⌥）键，部分键盘标为 Alt |
| `Return` | macOS / iPadOS 回车；Windows 表中写作 `Enter` |
| `Page Up / Page Down` | MacBook 通常为 `Fn + ↑ / Fn + ↓` |
| `Home / End` | MacBook 通常为 `Fn + ← / Fn + →` |
| `数字键盘` | 指独立小键盘；顶部数字行通常不能替代 |
| `N / P / B / W` | 放映状态下直接按字母，不加修饰键 |

注意：

- 文本编辑中的快捷键只有在文字插入点位于文本框或占位符内时才生效。
- `Ctrl/Cmd + A` 会根据焦点选择“当前文本”“当前页全部对象”或“全部幻灯片”。
- `Tab` 在编辑文字时插入/改变列表级别，在选中对象时则切换到其他对象；上下文决定结果。
- 笔记本的 F1—F12 若被系统用来调节音量或亮度，需要同时按 `Fn`。
- 中文输入法、截图软件、窗口管理器和浏览器可能先于 PowerPoint 截获按键。

## 9. 快捷键冲突、版本差异与自定义

### 9.1 上下文冲突

| 组合 | 不同上下文中的作用 |
|---|---|
| `Ctrl + D` | 选中对象时复制对象；选中幻灯片时可能复制幻灯片。不要用它关闭文件，关闭用 `Ctrl + W` |
| `Ctrl/Cmd + A` | 文本框内全选文字；幻灯片画布上全选对象；缩略图窗格内全选幻灯片 |
| `Tab` | 选中对象时切换对象；表格中移到下一格；编辑列表文字时改变级别或插入制表逻辑 |
| `Ctrl + S` | 编辑状态保存；Windows 放映状态打开“所有幻灯片” |
| `Ctrl + P` | 编辑状态打印；Windows 放映状态切换为笔 |
| `Ctrl + A` | 编辑状态全选；Windows 放映状态切换为箭头 |
| `E` | 编辑状态输入字母；Windows 放映状态擦除屏幕批注 |

### 9.2 常见失效原因

| 现象 | 常见原因 | 处理建议 |
|---|---|---|
| F1—F12 调节亮度/音量 | 系统把功能键当媒体键 | 加按 `Fn`，或修改系统键盘设置 |
| 功能区 Alt 序列不同 | Word/PowerPoint 显示语言或版本不同 | 按 `Alt` 后依屏幕 KeyTips 操作 |
| 放映键只输入文字 | 焦点仍在文本编辑，尚未开始放映 | 先用 `F5 / Shift + F5` 或 Mac 对应组合进入放映 |
| 对象层级键无效 | 没有选中对象，或焦点在对象内部文字 | 按 `Esc` 回到对象选择后重试 |
| `Control + Space` 无效 | 被 macOS 输入法切换占用 | 修改系统输入源快捷键，或从菜单清除格式 |
| 网页版打开浏览器功能 | 浏览器优先处理快捷键 | 使用网页功能区，或在桌面应用中打开 |
| 放映媒体键无效 | 使用的是在线视频而非插入的本地媒体 | 改用媒体控件或下载后插入本地文件 |
| 自定义组合被覆盖 | 加载项或系统全局热键占用 | 暂停冲突加载项/应用并重新绑定 |

### 9.3 自定义方法

#### Windows

PowerPoint for Windows 不像 Word 那样提供完整的“自定义键盘”界面。可选方案：

1. 把高频命令添加到“快速访问工具栏”，然后用 `Alt + 1`、`Alt + 2`……调用。
2. 为宏设置快捷键，或使用可信的 Office 加载项。
3. 利用功能区 KeyTips，为内置命令执行稳定的按键序列。

#### macOS

1. 进入 `工具 → 自定义键盘`。
2. 选择类别和命令，输入新组合并确认。
3. 若组合被系统占用，到 `系统设置 → 键盘 → 键盘快捷键` 修改系统绑定。

## 附：一分钟记忆法

- 文件操作：`N` 新建、`O` 打开、`S` 保存、`P` 打印、`W` 关闭。
- 幻灯片：Windows 用 `Ctrl + M` 新建，Mac 用 `Cmd + Shift + N`；加 `Shift + D` 复制当前页。
- 对象操作：`D` 复制，`G` 组合，方括号控制层级，方向键移动，`Alt/Option + ←/→` 旋转。
- 放映入口：Windows `F5 / Shift + F5 / Alt + F5`；Mac `Cmd + Shift + Return / Cmd + Return / Option + Return`。
- 放映控制：`N/P` 前进后退，数字加回车跳页，`B/W` 黑白屏，`Esc` 结束。
- Windows 放映指针：`Ctrl + L/P/A/E` 依次是激光笔、笔、箭头、橡皮擦。
