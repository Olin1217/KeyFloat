## 1. 符号与使用说明

| 写法 | 含义 |
|---|---|
| `Ctrl + S` | 同时按住 `Ctrl` 和 `S` |
| `Alt, H, F, S` | 依次按下，不必同时按 |
| `Shift + F3` | 笔记本可能要按 `Shift + Fn + F3` |
| `Cmd` | macOS 的 Command（⌘）键 |
| `Option` | macOS 的 Option（⌥）键，部分键盘标为 Alt |
| `Return` | macOS 回车键；Windows 表中写作 `Enter` |
| `Page Up / Page Down` | MacBook 通常为 `Fn + ↑ / Fn + ↓` |
| `Home / End` | MacBook 通常为 `Fn + ← / Fn + →` |
| `数字键盘` | 指独立小键盘；顶部数字行通常不能替代 |

注意：

- 中文输入法、显卡工具、截图工具、窗口管理器可能先于 Word 截获按键。
- 功能键若被系统用于亮度、音量等操作，需要同时按 `Fn`，或在系统设置中启用“将 F1、F2 等键用作标准功能键”。
- 功能区访问键会受 Word 显示语言、版本和加载项影响。按 `Alt`（Windows）后，屏幕上实时显示的字母最可靠。
- 下文的“向前/向后”按文档阅读方向理解；双向文字环境中的表现可能不同。

#### `Ctrl + Shift + V` 的版本冲突

微软近年的 Microsoft 365 Word 已把 `Ctrl + Shift + V` 设为“仅粘贴文本”，并把复制/粘贴文字格式改为 `Ctrl + Alt + C / V`。旧版和部分永久版 Word 常用 `Ctrl + Shift + C / V` 复制/应用格式，并用 `Ctrl + Alt + V` 打开“选择性粘贴”。请以当前 Word 的“自定义键盘”窗口为准。

## 7. 快捷键冲突、失效与自定义

### 7.1 Windows：查看或修改当前绑定

1. 进入 `文件 → 选项 → 自定义功能区`。
2. 在窗口底部“键盘快捷方式”旁单击“自定义”。
3. 在“类别”和“命令”中选择目标命令。
4. 查看“当前快捷键”，或在“请按新快捷键”中录入组合。
5. 建议保存到 `Normal.dotm`，使其对新文档生效；若只希望用于某个模板，就保存到该模板。
6. 使用“全部重置”前先确认，因为它会清除当前模板中的自定义绑定。

### 7.2 macOS：查看或修改当前绑定

1. 进入 `工具 → 自定义键盘`。
2. 选择类别和命令。
3. 查看现有按键，录入新组合并指定保存位置。
4. 若组合被 macOS 占用，到 `系统设置 → 键盘 → 键盘快捷键` 修改系统绑定。

### 7.3 常见冲突排查

| 现象 | 常见原因 | 处理建议 |
|---|---|---|
| `Ctrl + Space` 不清格式 | 被中文输入法用于切换输入源 | 更改输入法热键，或给 `ResetChar` 重新绑定 |
| F1—F12 调节音量/亮度 | 系统把功能键作为媒体键 | 加按 `Fn`，或修改系统键盘设置 |
| `Ctrl/Cmd + Shift + V` 行为不一致 | Microsoft 365 新旧版本映射不同 | 使用“选择性粘贴”，或检查自定义键盘 |
| `Alt` 组合无效 | 被菜单、显卡工具、远程桌面截获 | 关闭冲突程序，或按 `Alt` 后依屏幕 KeyTips 操作 |
| 网页版快捷键关闭标签页/切换标签 | 浏览器优先处理组合 | 改用 Word 网页版功能区，或在桌面应用中打开 |
| Mac 快捷键触发系统功能 | Spotlight、输入法、Mission Control 等占用 | 在 macOS“键盘快捷键”中修改系统组合 |
| 自定义键突然消失 | 绑定保存在未加载模板，或 `Normal.dotm` 被重建 | 检查“保存更改于”所指模板，并备份模板 |
| 同一快捷键执行了加载项命令 | COM/Office 加载项覆盖 | 暂停加载项并在“自定义键盘”中核对 |

### 7.4 命令名称速查（便于自定义）

在“自定义键盘”窗口里可搜索或定位这些常见命令：

| 目的 | 常见 Word 命令名 |
|---|---|
| 清除字符格式 | `ResetChar` |
| 清除段落格式 | `ResetPara` |
| 仅粘贴文本 | `PasteTextOnly`（名称依版本） |
| 复制/应用格式 | `CopyFormat / PasteFormat` |
| 插入批注 | `InsertAnnotation` 或 `NewComment`（依版本） |
| 修订 | `ToolsRevisionMarksToggle` |
| 显示编辑标记 | `ShowAll` |
| 应用样式 | `ApplyStyles` |
| 字数统计 | `ToolsWordCount` |
| 更新域 | `UpdateFields` |
| 插入脚注 | `InsertFootnote` |

## 附：一分钟记忆法

- 文件：`N` 新建、`O` 打开、`S` 保存、`P` 打印、`W` 关闭。
- 编辑：`X/C/V` 剪切/复制/粘贴，`Z/Y` 撤销/重做，`F/H/G` 查找/替换/定位。
- 字体：`B/I/U` 加粗/倾斜/下划线，`[`/`]` 调字号，`Space` 清字符格式。
- 段落：`L/E/R/J` 左/中/右/两端对齐，`1/2/5` 控制行距，`Q` 清段落格式。
- 结构：Windows 用 `Ctrl + Alt + 1/2/3`，Mac 用 `Cmd + Option + 1/2/3` 套标题级别。
- 长文档：`Ctrl/Cmd + F` 搜索，`Shift + F5` 回到上次修改处，`F9` 更新域。
