# KeyFloat software SVG source library

This directory is deliberately separate from KeyFloat's own brand assets.

- Root-level SVG files are the reviewed software marks used by the app.
- `source-packages/` preserves official downloadable brand archives when the source was a package.
- `official-icon-sources.json` records the first-party page, exact asset URL, source type, and presentation inset.
- Software with no suitable first-party SVG remains on KeyFloat's installed-app-icon or letter-mark fallback.
- The reviewed library currently contains 52 first-party SVG marks. Adobe product icons remain vendor originals, while all software icons share KeyFloat's common outer frame, corner radius, and per-mark optical inset.

Do not add a third-party logo aggregation, recreate a missing logo, or substitute a vendor-wide logo for a product-specific icon.
