# KeyFloat

KeyFloat 是一个置于桌面最前方的双语快捷键助手，包含 macOS 原生应用、Windows 应用、Web 官网和 Electron 原型。

## 目录

- `macos/`：当前 macOS SwiftUI/AppKit 应用（KeyFloat 1.0.5）
- `windows/`：当前 Windows 应用源代码（.NET）
- `web/`：官网、登录、反馈和授权服务端代码
- `electron/`：早期 Electron 原型
- `assets/`：品牌 Logo 与软件图标
- `archive/`：历史版本源代码快照

依赖目录、构建输出、安装包和本地环境文件未提交。请复制各目录中的 `.env.example` 并在本机配置密钥。
